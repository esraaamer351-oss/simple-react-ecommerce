# Nova Store — Simple React E-Commerce

A responsive beginner-friendly e-commerce application built with React.

## Features

- Fetch products from a REST API
- Product search
- Category filtering
- Product details page
- Add products to cart
- Increase/decrease quantity
- Remove products
- Cart total calculation
- Cart persistence with localStorage
- Responsive design

## Tech Stack

- React
- JavaScript (ES6+)
- React Router
- CSS3
- REST API
- Vite
- Git/GitHub

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## API

Product data comes from Fake Store API:
https://fakestoreapi.com/

## Project purpose

This project demonstrates practical React fundamentals including components, props, state, effects, API requests, routing, conditional rendering, array methods, and localStorage.
